# Missions

## Role

Les missions forcent le joueur a adapter equipement et programmation. Elles doivent annoncer les menaces dominantes avant le depart.

## Types de missions

- Elimination : detruire une cible ou un groupe.
- Recuperation : atteindre une ressource et l'extraire.
- Survie : tenir plusieurs tours.
- Assaut cible : attaquer une structure ou un chef ennemi.
- Reconnaissance : scanner une zone avec peu de combat obligatoire.
- Extraction : sauver une unite, un module ou une donnee.

## Informations affichees avant depart

- Type de menace dominante.
- Densite ennemie.
- Niveau de blindage moyen.
- Mobilite ennemie.
- Presence de zones dangereuses.
- Recompense principale.
