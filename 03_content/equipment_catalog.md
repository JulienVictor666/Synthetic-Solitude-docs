# Catalogue D'Equipements

## Capteurs

- Capteur optique standard : portee correcte, vision frontale.
- Radar circulaire : detection 360 degres, courte portee, information floue.
- Capteur thermique : detecte a travers la fumee, portee reduite.

## IA

- IA basique : comportement standard.
- IA de diagnostic : ajoute une ligne de script.
- IA cooperative : debloque les blocs de cooperation.

## Paquetage

- Kit de reparation : repare un allie proche.
- Munitions lourdes : assiste un robot avec arme lourde.
- Bouclier deployable : cree une zone defensive temporaire.

## Bras

- Bras de tir classique : equipe une arme legere.
- Bras stabilisateur : augmente la precision d'une arme lourde si immobile.
- Bras outil : necessaire pour reparation ou interaction complexe.

## Jambes

- Jambes equilibrees : standard.
- Jambes rapides : augmente le deplacement.
- Jambes lourdes : meilleure stabilite, mobilite reduite.

## Torse

- Blindage standard : bonne defense.
- Coque energetique : augmente l'energie disponible.
- Systeme de refroidissement : reduit les temps de recuperation.

## Armes

- Mitrailleuse legere : tir en mouvement, degats faibles mais rapides.
- Lance-flamme : courte portee, zone utile contre groupes.
- Fusil de precision : longue portee, necessite immobilite.
- Canon lourd : puissant, demande assistance ou stabilisation.
