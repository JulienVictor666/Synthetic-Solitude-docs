# Evenements De Hub

## Role

Les evenements de hub rythment la narration entre les runs. Ils doivent etre courts, recurrents et troublants.

## Moments recurrents

- Reveil dans la cuve de regeneration.
- Robots sortant de la ligne d'assemblage.
- Bruits d'impacts sur le bouclier du vaisseau.
- Messages de l'IA.
- Analyse de donnees recuperees.
- Silence inhabituel apres certaines missions.

## Evolution possible

1. L'IA parle seule.
2. Le heros se parle a lui-meme.
3. Le heros croit entendre les robots.
4. Les robots semblent repondre.
5. Le joueur ne sait plus si c'est reel ou mental.
