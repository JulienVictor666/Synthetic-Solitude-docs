# UI Et UX

## Objectif

Rendre un systeme complexe lisible et manipulable.

## Principes

- Les intentions ennemies doivent etre visibles sans ouvrir de menu profond.
- Les scripts doivent etre lisibles ligne par ligne.
- Les erreurs doivent etre expliquees.
- Les ordres du heros doivent etre rapides a donner.
- Le debug doit etre accessible mais non envahissant.

## Ecrans prioritaires

- Selection de mission.
- Equipement robot.
- Programmation robot.
- Combat.
- Resultat de run.

## Risque UX principal

Le joueur peut etre perdu si programmation, equipement et combat changent trop de choses en meme temps. Le tutoriel doit introduire les blocs progressivement.
